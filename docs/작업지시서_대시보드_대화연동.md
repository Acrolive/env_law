## 2. 작업 범위

### 작업 A — 대시보드에 대화 기록 파서 추가 (필수)
- 위치: `advice_dashboard/src/lib/parser/conversationLog.ts` (신규)
- 입력: `env_law/logs/conversations/*.md` (백필 파일 `backfill_*.md` 포함)
- 파싱 규칙: `## 🙋 사용자 [HH:MM:SS] (세션 xxxxxxxx)` / `## 🤖 Claude …` 헤더 단위로 분리,
  **사용자 질문 + 직후 Claude 답변을 1쌍(Q&A)으로 묶음**
- **자문 필터 (핵심)**: 아래 조건을 만족하는 Q&A 쌍만 인덱스한다.
  법령 자문 답변은 CLAUDE.md Hard Rule에 의해 출처 URL·템플릿이 강제되므로 판별 신뢰도가 높다.
  - 필수: Claude 답변에 `law.go.kr` URL 포함 (Hard Rule 3 — 모든 인용에 출처 URL 필수)
  - 보조(OR): `## 질의 요약`, `## 결론`, `근거 법령` 등 응답 템플릿 헤더 포함
  - 위 조건 미달 Q&A(프로젝트 셋팅, 스크립트 작업, 감사, 잡담 등)는 **인덱스에서 제외**
  - "근거 미확인 — API 응답 기준 확답 불가" 답변은 포함하되 `status: unverified`로 별도 표기
- 원본 로그(`logs/conversations/`)는 필터와 무관하게 전량 보존 (로컬 기록 목적 유지) —
  필터는 대시보드 파서 단계에서만 적용한다

### 작업 B — 데이터 모델 확장 (필수)
- `advice_dashboard/prisma/schema.prisma`에 `Conversation` 모델 신규 추가
  (Advisory와 분리 — 점수/인용 구조가 다르므로 혼합 금지)
  - 필드: `id`(project:date:session8), `project`, `date`, `session_id`, `messages_json`,
    `first_prompt`(목록 표시용), `message_count`, `updated_at`, `source_path`
- `npx prisma db push` 후 `scripts/rebuild-index.ts`에 대화 수집 추가

### 작업 C — 워처 감시 경로 추가 (필수)
- `src/lib/watcher.ts` `paths` 배열에 추가:
  ```ts
  path.join(DATA_ROOTS.env, "logs", "conversations"),
  ```
- 주의: 워처 `ignored`에 dotfile 제외 규칙(`/(^|[/\\])\../)이 있어
  `logs/conversations/.state.json` 변경은 무시됨 — 의도된 동작, 추가 조치 불요

### 작업 D — UI 노출 (필수)
- 신규 라우트: `/advice/conversations` (또는 기존 목록에 "대화 기록" 탭)
- 목록: 날짜 → 세션 → 첫 질문 미리보기 / 상세: 사용자·Claude 말풍선 형식
- **노출 정책**: 작업 A의 자문 필터로 비자문 대화(작업·잡담)가 원천 제외되므로
  **1안) 기존 OTP 로그인 사용자 전체 열람**으로 확정 (2026-07-21 발주자 방향 확인).
  role 분리(2안)는 불요.
- 검색(SearchBar) 인덱스: 자문 Q&A만 남으므로 **검색 포함 가능** — 단, 기존 Advisory와
  결과 구분 표시(배지 등) 필수

### 작업 E — 기존 데이터 백필 (권장)
- env_law에서 실행:
  ```bash
  ls -t ~/.claude/projects/-home-deploy-projects-tablet-projects-env-law/*.jsonl \
    | while read t; do node scripts/log_conversation.mjs --full "$t" \
      "logs/conversations/backfill_$(basename $t .jsonl | cut -c1-8).md"; done
  ```
- transcript 보존기한(기본 30일) 내 세션만 복원 가능함을 발주자에게 고지

### 작업 F — 데이터 품질 정리 (선택, G3 해결)
- `.omc/state` 루트의 완결 주제를 `sessions/<주제명_날짜>/`로 이동
  (예: `draft_chongryang*` → `sessions/총량제_20260511/`)
- 이동 후 워처가 자동으로 별건 Advisory로 재인덱스함

### 작업 G — 배포·검증 (필수)
1. `advice_dashboard`에서 `npm run build` 성공 확인
2. `sudo systemctl restart advice-dashboard`
3. 회귀 확인: 기존 Advisory 9건 유지 + Conversation 신규 표시
4. env_law에서 임의 대화 1턴 후 90초 내 대시보드 반영 확인 (워처 디바운스 1.5s + 증분 인덱스)
