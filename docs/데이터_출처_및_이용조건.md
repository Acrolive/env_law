# 데이터 출처 및 이용조건

## 포함 데이터

`data/대기오염물질_별표1_약어.csv` 및
`data/수질오염물질_별표2_약어.csv`는 물질명을 검색·표기할 때 쓰는 보조
대조표입니다. 각 행의 `출처구분`은 약어의 성격(예: 화학식, 관용 표기,
법정 표기)을 표시하며, 이 파일들은 법령 원문이나 공식 법령 데이터베이스를
대체하지 않습니다.

## 권위 있는 출처와 갱신

법령명, 조문, 별표, 시행일 및 법적 해석의 권위 있는 확인 경로는
[국가법령정보 공동활용 OpenAPI](https://open.law.go.kr/) 응답입니다. 이
저장소의 CSV는 API 응답과 원문 별표를 대조한 뒤에만 갱신해야 하며, 갱신 PR에는
확인한 법령명·별표·시행일·조회일을 기록해야 합니다. 원문 PDF/HWP의 표 구조와
수치·단위·행열 관계는 변환 결과만으로 확정하지 않습니다.

## 이용 및 재배포

저장소 안의 코드와 이 문서의 이용허락은 [ISC 라이선스](../LICENSE)를
따릅니다. 그러나 국가법령정보 서비스의 응답, 원문, API 이용조건 및 제3자
저작물에 관한 권리는 이 라이선스로 이전되지 않습니다. 데이터를 재배포하거나
상업적으로 이용하기 전에는 해당 서비스의 최신 이용약관, 출처표시 및 재이용
조건을 별도로 확인해야 합니다.

현재 CSV의 작성 이력에는 각 행의 원문 식별자와 취득일이 완전하게 기록되어 있지
않습니다. 따라서 완전성·최신성·법적 효력을 보증하지 않으며, 법령 판단에는
반드시 실행 시점의 API 원문을 다시 확인해야 합니다.
